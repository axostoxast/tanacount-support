証明写真のサイズ一覧

用途サイズ（縦×横）撮影の期限の目安主な決まり
履歴書・エントリーシート40×30mm3か月以内胸から上・正面・無帽。服装は面接に合わせる。応募先の指定があればそれに従う
パスポート（旅券）45×35mm6か月以内頭頂からあごまで34mm（±2mm）、無背景、正面、無帽。細かい規格は下の表
マイナンバーカード45×35mm6か月以内正面・無帽・無背景。顔がほぼ中央
運転免許証（持ち込み写真）30×24mm6か月以内正面・無帽・無背景・胸から上。持ち込みできるかは都道府県の窓口で確認
在留カード40×30mm3か月以内16歳以上が対象。正面・無帽・無背景

資格試験の願書なども40×30mmが多いですが、試験ごとに違います。受験案内で確認してください。

どの写真にも共通の決まり

  • 正面を向き、帽子やマスクを外す（宗教上・医療上の理由がある場合は申請先に相談）
  • 背景は無地（白・薄い青・薄いグレーなど）。影や柄が写らないようにする
  • ピントが合っていて、目がはっきり見える。前髪で目や輪郭が隠れない
  • 加工アプリで顔の形や肌を変えない（本人確認に使うため）
  • サイズは縦×横の順に書かれていることが多い（例：4×3cm＝縦4cm・横3cm）

パスポートの写真の細かい規格

写真の大きさ縦45mm×横35mm
顔の大きさ頭頂（髪を含む）からあごまで34mm（±2mm）
上の余白写真の上端から頭頂まで4mm（±2mm）
背景無地・無背景（影がない）
その他6か月以内に撮影、正面・無帽、縁なし。眼鏡は反射やフレームが目にかからないもの

規格は外務省・各都道府県の旅券窓口の案内に基づきます。申請前に最新の案内を確認してください。

スマホで撮って規格サイズに自動で合わせる →
背景を消した証明写真を作って、そのまま履歴書に。職務経歴書も例文から作れて、A4のPDFとL判の写真をコンビニで印刷できます。

コンビニでL判に印刷して安く作る

証明写真の画像をL判（89×127mm）に複数枚並べて作り、コンビニの写真プリントで印刷すると、証明写真機や写真館より安く用意できます。

  1. スマホで、無地の壁の前で撮影する（明るい窓の近くで、正面から光が当たるように）
  2. アプリで背景を整え、規格のサイズに合わせて、L判に並べた画像を保存する
  3. コンビニの写真プリント（L判）で印刷する。拡大・縮小やフチなし印刷はオフにする
  4. 印刷したら定規でサイズを確認し、線の内側で切り取る

L判1枚に、履歴書用（40×30mm）なら4枚、運転免許証用（30×24mm）なら9枚並べられます。

よくある質問

履歴書の写真のサイズは？

一般的には縦40mm×横30mmです。応募先から指定がある場合はそれに従います。

パスポートとマイナンバーカードの写真は同じサイズ？

どちらも縦45mm×横35mmです。ただし顔の大きさなどの細かい規格は、パスポートのほうが厳密に決められています。

スマホで撮った写真を証明写真に使ってもいい？

規格（サイズ・背景・撮影時期など）を満たしていれば使えます。加工で顔を変えるのは避け、申請先の注意事項を確認してください。
