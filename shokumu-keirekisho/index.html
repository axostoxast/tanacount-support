職務経歴書の書き方と職種別の例文

職務経歴書の書き方と、営業・事務・販売接客・ITエンジニア・介護の職種別の例文です。数字や固有名詞を自分の経験に置き換えて使ってください。

書き方のポイント

  • A4で1〜2枚：読み手は数分で目を通します。応募先に関係の深い経験を厚く書きます
  • 職務要約は3〜5行：最初に読まれる部分。経歴のあらましと強みを短く
  • 実績は数字で：件数・割合・金額・期間を入れると伝わります
  • 編年体か逆編年体か：古い順（編年体）が基本。直近の経験を強調したいときは新しい順（逆編年体）
  • 履歴書と食い違わない：会社名・在籍期間・資格の年月をそろえる

営業の職務経歴書 例文

職務要約

大学卒業後、株式会社〇〇にて法人営業として5年間従事しました。中小企業を中心に、新規開拓から既存顧客の深耕まで担当し、2年連続で売上目標を達成しました。顧客の課題を丁寧に聞き取り、最適な提案につなげることを強みとしています。

業務内容

  • 中小企業向けの〇〇（商材）の新規開拓営業
  • 既存顧客約40社のルート営業・アフターフォロー
  • 提案書・見積書の作成、価格交渉
  • 新人2名の同行指導

実績・取り組み

  • 2023年度 売上目標達成率118%（営業部20名中3位）
  • 新規取引先を年間12社獲得
  • 提案書のテンプレートを作成し、作成時間を約3割短縮

活かせる経験・知識・スキル

  • 法人向けの新規開拓営業（テレアポ・飛び込み・紹介）
  • 顧客の課題を聞き取り、提案にまとめる力
  • 数値目標に対する行動計画の立案と振り返り

自己PR

私の強みは、顧客の言葉にならない課題を聞き取り、解決策として形にする力です。前職では、価格を理由に失注が続いていた取引先に対し、運用面の負担を軽減する提案に切り替えたことで、年間契約の獲得につなげました。貴社でも、顧客の立場に立った提案で売上拡大に貢献したいと考えています。

事務の職務経歴書 例文

職務要約

株式会社〇〇にて営業事務として4年間、受発注・請求・在庫管理などのバックオフィス業務に従事しました。Excelの関数やマクロを使った業務改善に取り組み、月次集計の作業時間を削減しました。正確さとスピードを両立した事務処理を得意としています。

業務内容

  • 受発注処理（月約300件）、納期調整
  • 請求書・見積書の作成、入金確認
  • 在庫数の管理と発注点の見直し
  • 電話・メールでの顧客対応

実績・取り組み

  • Excelマクロで月次売上集計を自動化し、作業時間を月10時間削減
  • 請求書の二重チェック手順を作り、請求ミスをゼロに
  • 業務マニュアルを作成し、新任者の立ち上がりを2週間短縮

活かせる経験・知識・スキル

  • 受発注・請求・在庫管理などの営業事務全般
  • 正確でスピーディーなデータ入力
  • 業務手順の見直しとマニュアル化

自己PR

私の強みは、日々の業務の中から改善点を見つけ、仕組みにする力です。前職では、手作業で行っていた月次集計をExcelマクロで自動化し、チームの残業削減につなげました。貴社でも、正確な事務処理に加え、業務の効率化で組織に貢献したいと考えています。

販売・接客の職務経歴書 例文

職務要約

アパレル販売スタッフとして6年間、店頭での接客販売・売り場づくり・スタッフ育成に携わりました。副店長として売上管理やシフト作成も担当し、店舗の売上目標の達成に貢献しました。

業務内容

  • 店頭での接客販売、顧客管理
  • VMD（売り場づくり）と在庫管理
  • スタッフ5名のシフト作成・教育
  • 売上・客数のデータ分析と販売計画

実績・取り組み

  • 個人売上 年間〇〇万円（エリア15店舗中1位）
  • 売り場の配置を見直し、客単価を前年比110%に
  • スタッフの接客マニュアルを作成

活かせる経験・知識・スキル

  • お客様の要望を引き出す接客力
  • 売上データを見て売り場を改善する力
  • スタッフ教育・シフト管理

自己PR

私の強みは、お客様の様子から求めているものを察し、先回りして提案できることです。常連のお客様から指名をいただくことも多く、個人売上はエリアで1位になりました。貴社でもお客様に信頼される接客で、売上と店舗づくりに貢献します。

ITエンジニアの職務経歴書 例文

職務要約

Webアプリケーションエンジニアとして5年間、自社サービスの設計・開発・運用に携わりました。バックエンドを中心にフロントエンドやインフラも担当し、チームリーダーとして3名のメンバーをまとめました。

業務内容

  • 自社SaaSのバックエンド開発（Ruby on Rails、PostgreSQL）
  • フロントエンド開発（TypeScript、React）
  • AWS上のインフラ構築・運用（ECS、RDS）
  • コードレビュー、メンバー3名の技術指導

実績・取り組み

  • 決済機能のリプレースをリーダーとして完遂し、障害件数を半減
  • CI/CDを整備し、リリース作業を1回30分から5分に短縮
  • N+1の解消とキャッシュ導入で主要画面の表示速度を約2倍に改善

活かせる経験・知識・スキル

  • Webサービスの要件定義から運用までの一貫した開発経験
  • チームでの開発とコードレビュー
  • パフォーマンス改善・障害対応

自己PR

私の強みは、技術とビジネスの両方の視点で課題を捉えられることです。前職では、営業チームの要望を聞き取り、優先度を整理したうえで開発計画に落とし込みました。貴社でも、ユーザーにとって価値のある機能を素早く届けることで貢献したいと考えています。

介護・福祉の職務経歴書 例文

職務要約

介護福祉士として特別養護老人ホームで7年間、入居者の生活全般の介助に携わりました。ユニットリーダーとしてスタッフの指導や家族対応も担当しました。

業務内容

  • 食事・入浴・排せつなどの身体介護
  • ケアプランに沿った個別ケアの実施と記録
  • ユニットリーダーとしてスタッフ8名の指導
  • ご家族への状況説明・相談対応

実績・取り組み

  • 転倒リスクの高い方の動線を見直し、転倒事故を前年の半分に
  • 申し送りの様式を見直し、情報共有の漏れを削減
  • 新人向けの介助手順書を作成

活かせる経験・知識・スキル

  • 身体介護・認知症ケア
  • スタッフ指導とチーム運営
  • ご家族との信頼関係づくり

自己PR

私の強みは、入居者お一人おひとりの小さな変化に気づき、チームで共有できることです。体調の変化を早期に伝えたことで、重症化を防げた経験もあります。貴施設でも、利用者様が安心して過ごせるケアに努めます。

よくある質問

職務経歴書に決まった様式はある？

ありません。A4で1〜2枚にまとめるのが一般的です。応募先から指定がある場合はそれに従います。

職務経歴書は手書きのほうがいい？

パソコンで作るのが一般的です。PDFにしてメールで送ったり、印刷して持参したりします。
